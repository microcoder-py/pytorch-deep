# PyTorch Deep Dive

Finding all relevant resources to get started with deep learning can get hard. Knowing what to learn, and where to learn it from, is a task in itself. 

In this book, it is my intention to curate and collect relevant resources. If and only if there is insufficient documentation on a topic, or if it could be benefitted with some examples, will I add anything of my own. 

This is not a comprehensive tutorial series. It's more for exising practitioners looking to be pointed towards the right knowledge to fill in gaps. 

> **DISCLAIMER**: To keeps things clean and orderly, I use AI summarisers on my rough notes. The research, rough notes, were all written by me, only the final summary was cleaned up.
